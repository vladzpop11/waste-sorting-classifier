# Waste Sorting Classifier

Classify photos of waste into six recycling categories with transfer learning, trained on a free Kaggle GPU, exported to ONNX and served from Docker. Work in progress.

## Data

[TrashNet](https://github.com/garythung/trashnet) (Thung & Yang, 2016), MIT license: 2,527 photos in six classes (glass 501, paper 594, cardboard 403, plastic 482, metal 410, trash 137).
